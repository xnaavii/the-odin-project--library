# the-odin-project--library

### Description

Library project done with javascript, html and css. This project's purpose is to and grasp the prototypes concept.

[Live Site](https://xnaavii.github.io/the-odin-project--library/) · [Source Code](https://github.com/xnaavii/the-odin-project--library)

- Add books to the library
- Create new book
- Mark book as read
- Remove book
